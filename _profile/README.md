# Divesh Dogra

**Unity live-ops and gameplay engineer** · Mumbai, India · open to remote and relocation

I build mobile games in C# with Unity: league, clan, party and tournament systems, reward flows, and A/B-testing clients for live multiplayer games, plus a solo game of my own on the Play Store. Before games I worked as a VFX compositor on feature films.

[Portfolio](https://divesh567.github.io) · [LinkedIn](https://www.linkedin.com/in/divesh-dogra-2a689a191/) · [Download CV](https://divesh567.github.io/Divesh_Dogra_CV.pdf) · divesh476@gmail.com

## Shipped games

- **FAUG**, a competitive multiplayer FPS (Dot9 Games): league, clan and party-mode client features.
- **Chapter 26**, a casual multiplayer games hub (Dot9 Games): tournaments, leaderboards, clans, Arabic localization.
- **Mahabharat board game** and **Puzzles of Mahabharat** (BoredLeaders): a Ludo-style strategy game and a bilingual story-puzzle game.
- **Steady Light**, a 2D physics platformer I built solo, on the Play Store since Oct 2022 and still updated: [source](https://github.com/Divesh567/Steady_light).

## Selected projects

My work at Dot9 Games and BoredLeaders is closed source, so the repos below are my own projects.

- [Steady_light](https://github.com/Divesh567/Steady_light): the 2D physics platformer above, with event channels, Addressables levels and Firebase live-ops.
- [City-Builder](https://github.com/Divesh567/City-Builder): a city builder in Unity, written around object-oriented design.
- [ShaderGraphs](https://github.com/Divesh567/ShaderGraphs): Shader Graph effects.
- [Tanks-Multiiplayer](https://github.com/Divesh567/Tanks-Multiiplayer): a multiplayer tanks game in Unity.
- [Enemy-States](https://github.com/Divesh567/Enemy-States): enemy behaviour built as a state machine.
- [Battle_Deck](https://github.com/Divesh567/Battle_Deck): a card battle game prototype.

## Tools

C#, Unity (2022 LTS, Unity 6), Git, Photon PUN, Shader Graph, Firebase, Addressables, UniTask, DOTween, Mantis.
